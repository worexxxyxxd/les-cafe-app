# Кафе «Лес» — сайт

Сайт кафе «Лес» (Санкт-Петербург, Софийская ул., 22): шаверма и бургеры, работает круглосуточно.

**Страницы:** главная · меню · о нас · контакты.

- 3D-сцена «ночной лес» на Three.js: светлячки, парящая шаверма, бургер, костёр, метка на карте
- Адаптивная мобильная версия с нижней панелью «Меню / Маршрут / Позвонить»
- Меню на 29 позиций с категориями и поиском

Статический сайт, сборка не нужна: достаточно открыть `index.html`.

Данные (меню, цены, контакты, оценки) взяты с Яндекс Карт и могут отличаться от актуальных.
