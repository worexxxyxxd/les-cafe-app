# Лес — сайт сети кафе

«Лес» — уличная еда с русской душой: шаверма, бургеры, супы и закуски в Санкт-Петербурге.

**Страницы:** главная · меню · адреса · Будённого (франшизная точка) · о нас.

**Точки сети** (данные с Яндекс Карт, ноябрь 2026):
- Софийская ул., 22 — круглосуточно
- Московский просп., 62 — круглосуточно
- ул. Димитрова, 22, корп. 3 — круглосуточно
- Южное ш., 47, корп. 1 — ежедневно 11:00–23:00
- просп. Будённого, 19, корп. 1 — франшиза, своя страница `franchise.html` и своё меню

## Что внутри
- Фирменный стиль из печатного меню (Figma «Проект Лес»): шалфейные плашки, красные «ХИТ», логотип
- Меню сети по печатному меню: шаверма, тарелочки, бургеры, закуски, супы, напитки, допы, соусы; поиск и категории
- Мультяшные лесные жители (лиса, сова, ёжик, медведь-богатырь, заяц, белка, птичка) — моргают и подпрыгивают по клику
- Окно «Выберите свой Лес» для звонка и маршрута, статус «открыто» по времени Петербурга
- 3D-сцена «ночной лес» на Three.js с берёзами, адаптивная мобильная версия

## Где что менять
- `assets/data.js` — адреса, телефоны, часы работы точек
- `assets/menu-data.js` — меню сети и меню точки на Будённого
- `assets/animals.js` — рисунки зверят
- `assets/brand.css` — фирменный стиль (поверх `assets/style.css`)
- `assets/img/` — логотип и иконки сайта

## Шрифты
Текст — Montserrat (Google Fonts). Заголовки — **ST Izhora**: положите файлы шрифта в `assets/fonts/`
под именами `STIzhora.woff2` (и/или `.woff`, `.otf`, `.ttf`). Пока файлов нет, используется похожий Ruslan Display.

Статический сайт, сборка не нужна: достаточно открыть `index.html` или выложить папку на любой хостинг.
